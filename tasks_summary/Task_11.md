# Task 11: модель памяти агента

Дата: 2026-09-14

## Что сделали

Добавили явную модель памяти агента с тремя типами памяти:

- краткосрочная память — текущий диалог;
- рабочая память — данные текущей задачи;
- долговременная память — профиль, решения и знания.

Для новой модели добавлена стратегия контекста:

```text
memory
```

Она используется по умолчанию. Переключаться вручную не нужно, если нужна новая
модель памяти из этого задания. Переключатель стратегий оставлен для сравнения
со старыми режимами `sliding_window`, `summary`, `sticky_facts` и `branching`.

## Хранение

Разные типы памяти хранятся отдельно:

```text
memory/users/1/messages.json
memory/users/1/working_memory.json
memory/users/1/long_term_memory.json
```

Пути можно переопределить через переменные окружения:

```text
AGENT_HISTORY_FILE
AGENT_WORKING_MEMORY_FILE
AGENT_LONG_TERM_MEMORY_FILE
AGENT_USER_ID
```

По умолчанию используется пользователь `1`. Для другого пользователя можно
задать `AGENT_USER_ID`, и все три типа памяти будут храниться в отдельной
подпапке этого пользователя. `AGENT_USER_ID` не должен быть пустым и не должен
содержать разделители пути.

## Правила записи

Выбор хранилища сделан явно в `ChatService` отдельными методами сохранения:

- `_save_short_term_memory()` сохраняет текущий диалог через `MessageHistoryRepository`;
- `_save_working_memory()` сохраняет данные текущей задачи через `WorkingMemoryRepository`;
- `_save_long_term_memory()` сохраняет профиль, решения и знания через `LongTermMemoryRepository`.

Краткосрочная память хранит последние сообщения диалога и ограничивается
`AGENT_RECENT_MESSAGES_LIMIT`.

Рабочая память хранит только состояние активной задачи: цель, требования,
ограничения, выбранный подход, файлы, команды, статус, открытые вопросы и
следующие шаги. Она не хранит профиль пользователя или долговременные решения.

Долговременная память хранит только устойчивую информацию, полезную в будущих
сессиях. Она разделена на секции:

- `profile` — профиль пользователя, проекта и устойчивые предпочтения;
- `decisions` — долговременные решения и договоренности;
- `knowledge` — повторно используемые знания о домене или проекте.

Новые доменные сущности:

- `domain/agent_memory.py` — `MemoryType` и `AgentMemorySnapshot`;

- `application/memory/long_term_memory_repository.py`;
- `application/memory/working_memory_extractor.py`;

- `SimpleWorkingMemoryExtractor`;
- `SimpleLongTermMemoryExtractor`.

## Поведение стратегии memory

При новом сообщении:

1. `ChatService` загружает краткосрочную, рабочую и долговременную память.
2. Новое сообщение пользователя добавляется в краткосрочную память.
3. Агент получает последние сообщения плюс контекст из рабочей и долговременной памяти.
4. После ответа агента в краткосрочную память добавляется ответ ассистента.
5. Рабочая память обновляется только данными текущей задачи.
6. Долговременная память обновляется только устойчивыми фактами, решениями и знаниями.
7. Каждый тип памяти сохраняется в свое хранилище.

PyQt UI получил новую стратегию `Memory` в переключателе стратегий. Очистка
контекста для этой стратегии очищает все три соответствующих файла памяти.
