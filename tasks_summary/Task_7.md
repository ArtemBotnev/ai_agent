# Task 7: сохранение контекста агента

Дата: 2026-09-08

## Что сделали

Добавили агенту сохранение истории диалога между перезапусками. Теперь сообщения пользователя и ответы агента сохраняются в JSON-файл, а при новом запуске приложения история загружается обратно и передается в LLM как контекст.

История по умолчанию хранится в:

```text
history/messages.json
```

Путь можно переопределить через переменную окружения:

```text
AGENT_HISTORY_FILE
```

## Архитектура

Реализация сделана в стиле чистой архитектуры:

- `domain/message.py` — доменная сущность `Message`.
- `application/message_history_repository.py` — порт `MessageHistoryRepository` для загрузки и сохранения истории.
- `application/llm_agent.py` — порт `LlmAgent`, через который application layer обращается к LLM.
- `application/agent_error.py` — ошибки агента и коды ошибок.
- `application/chat_service.py` — use case диалога: загрузить историю, добавить сообщение пользователя, вызвать агента, сохранить ответ.
- `infrastructure/json_message_history_repository.py` — JSON-реализация хранилища истории.

## Изменения в существующем коде

- `agent.py` теперь принимает список сообщений `Message` и отправляет в Responses API всю историю, а не только последнее сообщение пользователя.
- `main.py` теперь собирает `ChatService`, JSON-репозиторий и LLM-агента.
- `web/server.py` теперь обрабатывает `/api/chat` через `ChatService`.
- `web/server.py` получил новый endpoint `GET /api/messages`, который возвращает сохраненную историю для web-интерфейса.
- `web/static/app.js` теперь при загрузке страницы запрашивает `/api/messages` и восстанавливает историю сообщений в интерфейсе.

## Поведение

При отправке сообщения:

1. `ChatService` загружает историю из `history/messages.json`.
2. Добавляет новое сообщение пользователя.
3. Передает всю историю в `SimpleLlmAgent`.
4. Получает ответ LLM.
5. Добавляет ответ агента в историю.
6. Сохраняет обновленную историю обратно в JSON.

Если приложение перезапустить, сохраненные сообщения будут загружены снова, и следующий запрос будет отправлен в LLM вместе с прошлым контекстом.
