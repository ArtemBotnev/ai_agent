# Task 12: персонализация и выбор пользователя

Дата: 2026-09-15

## Что сделали

Добавили персонализацию поверх модели памяти через ручной markdown-профиль
пользователя.

Профиль хранится отдельно от runtime-памяти:

```text
profiles/users/<user_id>/profile.md
```

Путь можно переопределить через переменную окружения:

```text
AGENT_USER_PROFILE_FILE
```

По умолчанию используется тот же пользователь, что и для памяти:

```text
AGENT_USER_ID=1
```

Добавлен пример профиля:

```text
profiles/example/profile.md
```

Runtime-директория пользовательских профилей добавлена в `.gitignore`:

```text
/profiles/users/
```

## Структура профиля

Профиль заполняется вручную в markdown и может содержать:

- роль пользователя;
- предпочтения по стилю;
- предпочтения по формату;
- ограничения.

Для пользователя `1` добавлена роль:

```text
Android-разработчик
```

Пример секций:

```text
## Role
## Style
## Format
## Constraints
```

## Архитектура профиля

Добавлены:

- `domain/user_profile.py` — доменная сущность `UserProfile`;
- `application/memory/user_profile_repository.py` — порт чтения профиля;
- `infrastructure/markdown_user_profile_repository.py` — markdown-реализация профиля.

`UserProfile.to_context()` рендерит markdown-профиль в отдельный блок:

```text
User profile and preferences:
...
```

## Подключение к запросам

Профиль выбранного пользователя добавляется в контекст каждого запроса.

В стратегии `memory` профиль входит в `AgentMemorySnapshot` и идет перед рабочей
и долговременной памятью.

Для остальных стратегий профиль добавляется через общий context-builder в
`ChatService` перед strategy-specific контекстом:

- `sliding_window`;
- `summary`;
- `sticky_facts`;
- `branching`.

Если файл профиля отсутствует или пустой, агент работает как раньше.

Профиль не очищается через `/clear`, потому что это ручные пользовательские
настройки, а не состояние диалога.

## Выбор пользователя в PyQt UI

Добавили выбор пользователя в PyQt UI, если в проекте найдено больше одного
пользователя.

Пользователи определяются по директориям:

```text
memory/users/<user_id>/
profiles/users/<user_id>/
```

Текущий `AGENT_USER_ID` тоже включается в список, даже если директория для него
еще не создана.

Если доступен один пользователь, UI не показывает лишний переключатель.

Если пользователей больше одного, в верхней панели появляется список
`Пользователь`. Выбранный пользователь используется для:

- истории сообщений;
- рабочей памяти;
- долговременной памяти;
- markdown-профиля пользователя.

При смене пользователя PyQt UI перезагружает историю выбранного пользователя.
