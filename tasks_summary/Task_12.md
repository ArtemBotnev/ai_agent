# Task 12: выбор LLM

Дата: 2026-09-14

## Что сделали

Оставили текущую модель по умолчанию:

```text
gpt-3.5-turbo-0125
```

Добавили общий список доступных LLM-моделей:

```text
gpt-3.5-turbo-0125
gpt-4o-mini
gpt-4o
gpt-5
```

Список хранится в `agent.py` как `AVAILABLE_OPENAI_MODELS`, а остальные слои
получают его через `get_available_model_names()`.

## Переключение

CLI получил команду:

```text
/model
/model gpt-4o-mini
```

Без аргумента команда показывает текущую модель и список доступных. С аргументом
она переключает модель для следующих сообщений.

PyQt UI получил выпадающий список моделей в верхней панели. Выбранная модель
передается в `build_chat_service()` при отправке сообщения.

Web UI теперь получает список моделей через `/api/config`, показывает select и
передает выбранную модель в `/api/chat`.

## Поведение

Если модель не выбрана явно, используется `OPENAI_MODEL`, а если переменная
окружения не задана, используется дефолтная модель `gpt-3.5-turbo-0125`.

Если указана модель не из списка `AVAILABLE_OPENAI_MODELS`, приложение возвращает
ошибку конфигурации модели.
