# Task 8: подсчет токенов агента

Дата: 2026-09-09

## Что сделали

Добавили агенту подсчет токенов для каждого нового запроса. Теперь после ответа модели приложение показывает:

- токены текущего сообщения пользователя;
- токены всей истории диалога, которая отправляется в модель;
- токены ответа модели.

Подсчет входных токенов выполняется через OpenAI Responses API endpoint:

```text
/v1/responses/input_tokens
```

Токены ответа берутся из поля `usage.output_tokens` в ответе модели.

## Архитектура

Реализация сохранена в стиле чистой архитектуры:

- `application/llm_agent.py` — порт `LlmAgent` теперь умеет считать токены через `count_tokens()` и возвращает `LlmAnswer`, а не простую строку.
- `application/chat_service.py` — use case диалога собирает `ChatResponse` с текстом ответа и статистикой `ChatTokenUsage`.
- `agent.py` — инфраструктурная реализация `SimpleLlmAgent` знает конкретные OpenAI endpoints и формат ответа API.
- `web/server.py` — HTTP-слой отдает токены клиенту в JSON-ответе `/api/chat`.
- `web/static/app.js` — web-интерфейс показывает токены под новым ответом агента.
- `main.py` — CLI выводит токены после ответа агента.

`JsonMessageHistoryRepository` не изменяли: история по-прежнему хранит только сообщения диалога, без технической статистики конкретных запросов.

## Изменения в существующем коде

- В `application/llm_agent.py` добавлен `LlmAnswer`.
- В протокол `LlmAgent` добавлен метод `count_tokens(messages)`.
- В `application/chat_service.py` добавлены `ChatTokenUsage` и `ChatResponse`.
- `ChatService.answer()` теперь возвращает объект `ChatResponse`.
- `SimpleLlmAgent` теперь:
  - считает входные токены через `/v1/responses/input_tokens`;
  - отправляет основной запрос в `/v1/responses`;
  - возвращает текст ответа и количество output-токенов.
- В `application/agent_error.py` добавлен код ошибки `MISSING_TOKEN_USAGE`.
- `/api/chat` теперь возвращает ответ вида:

```json
{
  "answer": "...",
  "tokens": {
    "current_request": 12,
    "history": 340,
    "response": 85
  }
}
```

## Поведение

При отправке сообщения:

1. `ChatService` очищает новое сообщение пользователя от лишних пробелов.
2. Загружает историю из `history/messages.json`.
3. Добавляет текущее сообщение пользователя к истории.
4. Просит агента посчитать токены текущего сообщения.
5. Просит агента посчитать токены всей истории, которая будет отправлена в модель.
6. Отправляет историю в LLM.
7. Получает текст ответа и количество токенов ответа.
8. Добавляет ответ агента в историю.
9. Сохраняет обновленную историю обратно в JSON.
10. Возвращает текст ответа и статистику токенов вызывающему слою.
